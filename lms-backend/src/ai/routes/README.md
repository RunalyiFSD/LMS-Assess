# Routes

## Purpose
Defines the Express router and endpoints for the AI module.

## Responsibilities
- Map URL paths (e.g., `/api/v1/ai/evaluate`) to AI Controller methods.
- Apply appropriate middleware (e.g., authentication, AI-specific rate limits).

## Future Extension Points
- Adding new AI feature routes.
- Versioning the AI API (e.g., `/v2/ai/`).
