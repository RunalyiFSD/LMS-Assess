# Constants

## Purpose
Centralized storage for all magic strings, limits, and configurations related to the AI module.

## Responsibilities
- Define allowed providers (e.g., `openai`, `gemini`).
- Define known model names (e.g., `gemini-2.5-pro`).
- Define token limits and timeout values.

## Future Extension Points
- Adding new models as they are released without hunting through service files.
